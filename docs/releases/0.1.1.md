# 聊天军师 0.1.1 · 悬浮稳定性、记录保存与联系人导入

发布日期：2026-09-30。Android 11+、ARM64；`com.ltrj.chatadvisor`；versionCode 2。
基于 0.1.0 分支继续开发，原来的 main、version/0.1.0 和 v0.1.0 保留。

## 修复与新增

- 悬浮球依据真实应用窗口判断前台，不再直接用键盘、系统窗口或面板事件覆盖微信身份；增加窗口变化监听和定期状态核对、挂载恢复、旋转位置修正、解锁后的显示恢复。
- 截图期间临时隐藏与恢复独立管理。截图失败保留已有会话；快速重复点击和切换会话时丢弃迟到结果。主页显示服务实际连接状态，主页和常驻通知提供恢复入口。
- 新增本地草稿及成功建议记录：保存文字、说话人、关系背景、目标、分析、三条候选和联系人关联；不保存原截图。可继续草稿、查看历史、复制推荐或全部候选、删除单条及清空建议记录。
- 记录以完整快照原子写入并核对磁盘内容；写入失败提示重试，不声称成功。修改后重新分析生成新历史条目，不覆盖原建议；历史不会自动发送给模型。
- 聊天校对页可选择已有联系人，或保存当前名称、关系和手动备注。联系人按 ID 关联，改名不会改变关联；删除联系人保留建议记录并解除关联。
- 联系人可粘贴文本或导入 TXT（UTF-8、UTF-8 BOM、GB18030，每次最多12000字、文件最多256KB），使用配置的回复模型识别多人资料。
- 提取内容必须引用原文，未知字段留空；先核对、编辑，再逐位保存。同名/别名需明确选择新增或合并，合并时核对关系与备注，不静默覆盖。
- 识别格式错误最多重新请求一次；失败或取消保留原输入，旧回调不显示、不写入联系人。修正联系人页已失效的快捷操作提示及保存失败提示。
- 共享截图预览增加布局完成后的坐标调用保护；这不代表截图导入已完成修复或真机验收。

## 验证

- `testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest` 构建成功；60项 JVM/Robolectric 测试通过，0失败；Lint 0错误、26警告。
- 新增19项测试覆盖持久化读写、原子更新与备份恢复、存储损坏/失败、联系人解绑、清空范围、原文提取、编码与上限、格式重试、窗口选择以及实际 Activity 保存/恢复/复制/联系人操作。
- APK仅含ARM64原生库；v2签名及16KB对齐检查通过；与0.1.0的开发签名一致，可覆盖安装。
- 本次ADB没有连接设备，未声称0.1.1已在雷电或微信真机运行通过。未配置真实模型密钥，文本智能导入使用匿名结构化样例验证，真实服务商调用仍需实测。

## 已知限制与待测

- 微信悬浮稳定性须在你的手机上复测；系统或ROM停止无障碍服务时，需要通过恢复入口重新连接，不保证服务永久常驻。
- 截图导入完整修复按用户要求留待后续。共享布局保护不替代解码、系统选择器及原生OCR完整验收。
- 文本智能导入需要已配置的回复接口，所有提取结果必须由用户核对；群聊、语音、图片理解不属于本轮功能。
- 0.1.0已丢失的内存内容不能恢复。草稿仅保留当前一轮，成功生成的建议保留独立历史；卸载或清除应用数据会删除本地记录和密钥。

## 升级及下载

直接安装 `chat-advisor-0.1.1-debug.apk` 覆盖0.1.0；不要先卸载或清除数据。原有接口设置、联系人及笔记保留。
首次升级后建议：粘贴聊天生成一次 → 返回主页查看“聊天与建议记录” → 重启应用确认保留；再测试联系人快捷保存和文本导入，最后在微信检查键盘开关/返回聊天/锁屏解锁后的悬浮入口。
