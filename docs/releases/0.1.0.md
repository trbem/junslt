# 聊天军师 0.1.0 · 首次发布

发布日期：2026-09-30。Android 11+、ARM64，应用 ID `com.ltrj.chatadvisor`。
此版本保留原交付 APK，不包含 0.1.1 的修复。

## 已有功能

- 基于 Jev Android 与狗头军师规则，提供军师分析及恰好三条可复制候选。
- 用户点击悬浮球触发一次截图，本机中文 OCR；校对文字、说话人和顺序后确认分析。
- 提供粘贴聊天文本和截图导入入口；截图导入存在已知故障，见下文。
- Jev 判断、生成模型编写回复、Jev 排序；判断和排序失败时明确降级。
- 支持模型接口配置、连通测试和手动联系人、笔记管理。
- 复制仅包含候选正文，由用户手动粘贴发送；无自动发送、账号或中转服务器。

## 验证情况

- Android 构建通过；41 项 JVM 测试通过；Lint 0 错误、24 警告。
- 雷电 Android 14 上安装原 ARM64 APK，3 项仪器测试通过：主页与配置身份、确认与说话人校验、候选复制及编辑撤销结果。测试使用固定匿名样例。
- 用户自行在手机测试并反馈：生成建议回复逻辑可用。手机、Android、微信版本和模型配置未提供，未将此反馈扩大为所有手机通过。
- 微信悬浮稳定性和原生截图/OCR完整流程未完成开发侧真机验收；模拟器无法使用微信。
- APK v2 签名和 16 KB zipalign 检查通过。

## 已知问题

- 用户反馈：已开启相关设置，悬浮窗口仍经常消失。
- 用户反馈：导入聊天截图不可用，后续版本再修复。
- 聊天文字与军师建议只存于进程内存，再次使用或进程退出可能丢失；此版本没有持久化建议历史。
- 联系人缺少当前聊天快捷保存和模型辅助文本导入。
- 联系人管理页包含失效的快捷操作提示，不能据此认为功能已完成。

## 安装及数据

安装 Release 中的 `chat-advisor-0.1.0-debug.apk`，按安装与 API 配置说明填写自己的接口。
这是自用开发签名版本。联系人、笔记和接口设置保存于本机；截图、聊天和分析结果只在内存中。
不要卸载或清除应用数据来升级；后续同包名、同签名且版本号更高的 APK 可覆盖安装。
