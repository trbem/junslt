# 下一版本计划

## 0.1.1 · 尚未实现

- 悬浮窗：正确识别底层应用，避免键盘、系统窗口和自己的面板造成错误隐藏；截图结束、服务重连、解锁和旋转后恢复状态，并提供恢复入口。
- 记录保存：草稿和成功结果保存于本机，包含校对文字、背景、目标、分析及三条候选；不保存截图。历史页支持查看、关联联系人、复制和删除，重启后仍保留。历史不自动发送给模型。
- 联系人快捷操作：当前聊天可选择已有联系人或新建，联系人详情可查看关联建议。
- 文本导入：粘贴或选择 TXT，使用已配置的回复模型提取联系人，核对编辑后保存；支持多位联系人和重复项确认，不推断原文未提供的个人事实。
- 兼容升级：保留包名、开发签名、现有接口设置与手动资料，版本号升为 0.1.1 / versionCode 2。
- 验证：覆盖窗口切换、记录重启恢复、写入失败、过期请求丢弃、联系人解析和导入失败；微信相关流程仍需真实手机复测。
