# 版本分支与发布规则

- 目标仓库：`trbem/junslt`。`main` 保留首次上传的 0.1.0 基线，后续版本不自动合入。
- 每个版本使用 `version/X.Y.Z` 分支，从上一版本分支继续开发；完成修改和验证后推送。
- 已发布分支和标签不覆盖，不强制推送；修正发布后的代码或文档通过新版本进行。
- Android `versionName` 对应版本，`versionCode` 每次可安装升级递增；覆盖安装使用同一签名，签名材料不进入仓库。
- 每个版本更新 `CHANGELOG.md`，新增 `docs/releases/X.Y.Z.md`，写明新增、修复、验证、已知问题和升级方式。
- 已完成版本创建 `vX.Y.Z` 标签和 GitHub Release，附 APK、源码包、安装说明及 `SHA256SUMS.txt`。
- 未完成版本明确标注开发中/计划中，不提前创建正式发布或声称修复完成。
- 发布前检查密钥、签名文件、本机 SDK、缓存和个人聊天资料；APK 校验值必须与本次交付一致。
- 当前工作源码位于 `D:\ltrj\chatadvisor`，0.1.0 发布镜像位于 `D:\ltrj\publish-junslt`。后续版本工作应从发布仓库上一版本分支开始，避免误推上游 Jev 仓库。
